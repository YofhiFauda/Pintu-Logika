## Deskripsi

<p align=justify>
Pintu Logik adalah sebuah media pembelajaran interaktif berbasis Android yang dirancang untuk membantu siswa Sekolah Menengah Kejuruan (SMK), khususnya di SMKN 1 Ngadirojo, dalam memahami konsep Aljabar Boolean dan Gerbang Logika dengan cara yang lebih menarik, mudah, dan kontekstual.

Aplikasi ini hadir sebagai solusi atas keterbatasan media pembelajaran konvensional seperti buku teks dan metode ceramah yang kurang mampu memvisualisasikan keterkaitan antara teori dan penerapan konsep logika digital. Melalui fitur simulasi interaktif, visualisasi animasi gerbang logika, serta kuis adaptif, siswa dapat belajar secara mandiri dan memperoleh pengalaman belajar yang lebih bermakna.

Dengan mengusung pendekatan pembelajaran berbasis teknologi informasi dan komunikasi (TIK), Pintu Logik memungkinkan siswa untuk belajar kapan pun dan di mana pun melalui perangkat Android. Aplikasi ini juga membantu meningkatkan motivasi belajar dengan tampilan antarmuka yang menarik, navigasi yang mudah, serta materi yang disusun secara sistematis mulai dari pengenalan Aljabar Boolean hingga penerapan berbagai jenis gerbang logika seperti AND, OR, NOT, NAND, NOR, XOR, dan XNOR.
</p>



## Fitur yang tersedia
- Dapat melakukan Login
- Materi Interaktif.
- Simulasi Gerbang Logika
- Tabel Kebenaran Otomatis
- Gamifikasi Untuk Aljabar Boolean dan Gerbang Logika.
- Mini CMS untuk Admin

## Teknologi yang digunakan
- Android Studio
- Kotlin
- Android Jetpack Component
- Firebase
- dotsindicator
- ImageKit.io
- Gson converter
- Retrofit
- Okhttp
- Logging
- Coroutines


## Cara menjalankan aplikasi
***Kamu bisa install dan mencoba Aplikasi Pintu Logika di bawah ini 👇***

[![Pintu Logika](https://img.shields.io/badge/Pintu%20Logika%20%E2%9C%85-APK-red.svg?style=for-the-badge&logo=android)]()

### 1. Persyaratan
  - Android 10.0 Q Keatas
  - Koneksi Internet
  - Perizinan Penyimpanan

### 2. Instalasi
  - Download Aplikasi dengan Link di atas atau pergi ke release
  - Install Aplikasi
  - Melakukan Perizinan untuk Penyimpanan

### 3. Testing Device
  - Android Emulator Pixel 3a API 34 
  - Android Emulator Pixel 3a API 29
  - Emulator Blue Stack Android 11
  - Redmi Note 7 Android 10
  - Redmi Note 9 Android 12
  - Redmi Note 13 Android 12
